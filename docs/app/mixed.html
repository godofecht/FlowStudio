Python + R, one browser workflow

Python computes a sum in Pyodide; JavaScript validates and transfers the numeric result; R computes its square root in webR. Both interpreters execute in WebAssembly in your browser, with no FlowStudio server.

Important: the coordinator on GitHub Pages is JavaScript, not compiled Flow. For native Flow orchestration, see the Flow server example.
