FlowStudio

A Flow-first scientific workspace. Edit, explore and run Flow, R and Python locally, with a Flow-native execution core and an independent browser interface.

Launch browser IDEFind a releaseFeature parity tracker

Early preview. Not RStudio feature parity. Untrusted code is not sandboxed; the native server must remain on localhost. The browser IDE runs Python with Pyodide and experimental R with webR (downloaded from third-party CDNs); Flow execution still requires the native runtime. GitHub Pages does not run a server or execute user code.

Inside the workspace

Source and projects

Browser-mediated file access, basic editor operations, source cells, find/replace and project search.

Flow-owned execution

Flow routes execution of Flow, R and Python source through a loopback-only native HTTP server.

Scientific workflows

Early console, tabular-viewer and plot interfaces, with documented verification gaps.

Getting started

Download a package for macOS arm64 or Linux x86-64 from the versioned GitHub Release. Extract it and run from the extracted directory:

./run.sh

Open http://127.0.0.1:8751. Flow 2.x is required for executing Flow code; Python and R are separately installed as needed. See the README for build and test instructions and the release notes for limitations.
