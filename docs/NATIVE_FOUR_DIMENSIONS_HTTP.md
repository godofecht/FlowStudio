# Native four-unknown SI dimensions: production acceptance

The checked-in `src/math_dimension_four.flow` implements a bounded four-unknown, four-equation dimensional constraint solver in the upstream Flow 2.0 mathematical postfix IR. The `src/math_dimension_four_smoke.flow` executable asserts 11 positive and negative cases: 4×4 full-rank constraints, square-root constraints, Unicode bindings, integer exponent rejection, rank deficiency, unsupported addition, unknown symbols, duplicate unknowns, known dimension bindings, binding collision and excessive binding counts.

The live native HTTP acceptance in `tests/http_smoke.py` concatenates the actual seven checked-in Flow modules (112,258 UTF-8 bytes at introduction), removes only local imports and `export` visibility, and calls `POST /api/check/flow` followed by `POST /api/run/flow`. It requires the native success marker, deliberately changes a valid fourth-power length constraint into an inconsistent 3m constraint and requires HTTP 422, and corrupts the real determinant function declaration and requires compiler HTTP 422. No Python dimensional solver or mock HTTP response is used.

The physical Chromium acceptance in `tests/native_math_plot_ui.mjs` loads those same seven modules into Monaco and clicks the workbench's actual Run control. It requires the native Flow program's success marker in the visible console. The CI source/transport, native compiler/HTTP and R/C FlowJIT jobs on Linux/macOS must pass independently. Ubuntu Chromium is the browser platform exercised by this scenario; independent macOS physical-browser interaction is not claimed.

**Verified:** [exact-head PR CI #41193965464](https://github.com/godofecht/FlowStudio/actions/runs/41193965464) passed all six Linux/macOS jobs, including real Flow HTTP check/run, negative HTTP 422 cases, Ubuntu physical Chromium Monaco Run, and native R/C FlowJIT. The source/transport suites passed 1,170 JavaScript tests (12 skipped) and 399 Python tests (13 skipped) per platform. **Unexecuted:** local native Flow/R, independent macOS physical-browser interaction, and post-merge main CI. This is a deliberately bounded four-equation SI inference feature, not a general tensor or PDE compiler, and does not establish RStudio parity.
